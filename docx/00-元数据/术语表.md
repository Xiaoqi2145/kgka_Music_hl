## 1. 项目与领域术语

| 中文名（唯一） | 代码名 | 定义 | 禁止写成 |
|---|---|---|---|
| KA Music | `kgka_music_hl`（package 名） | 本 Flutter 音乐客户端项目 | 开音乐、KA音乐 |
| 曲目 / 歌曲 | `Song` | 一首音乐作品的领域模型，含 hash、id、标题、歌手、专辑、时长、封面 | 单曲、音乐 |
| 歌曲 Hash | `Song.hash` | 酷狗侧曲目唯一标识，优先作为键 | 歌曲ID |
| 音质 | `AudioQuality` | 播放码率档位：标准 128K / 高品质 320K / 无损 FLAC | 码率、清晰度 |
| 智能音质 | `settings.smart_quality_enabled` | 播放失败时自动降级到更低音质重试 | 自动音质 |
| 播放地址 | `PlayUrl` | `/song/url` 返回的播放信息，含 URL、音质、码率、大小、响度 | 播放链接 |
| 响度数据 | `LoudnessData` | LUFS / 建议增益 / 峰值三元组，用于音量均衡 | 音量数据 |
| 音量均衡 | `VolumeNormalizationService` | 基于 LUFS 的跨曲目音量归一化 | 音量标准化、音量平衡 |
| 参考响度 | `referenceLufs` | 音量均衡的目标 LUFS，用户可见默认 −14，范围 −16 ~ −6；⚠️ 服务侧默认常量为 −11（见 TD-41） | 目标音量 |
| 播放缓存 | 播放缓存（`ka_music_play_cache`） | 播放过程中自动落盘的音频分片缓存，LRU 上限 300MB 默认 | 音频缓存 |
| 缩略图缓存 | 缩略图缓存（`ka_music_artwork`） | 封面图磁盘缓存，LRU，默认上限 512MB | 图片缓存、封面缓存 |
| 数据缓存 | `CacheService`（`ka_music_cache`） | 接口 JSON 的 SWR 缓存，分级 TTL | 接口缓存、JSON 缓存 |
| 下载 | `DownloadService`（`ka_music_downloads`） | 用户主动发起的完整音频文件下载，无上限 | 离线缓存 |
| SWR | Stale-While-Revalidate | 先返回陈旧缓存，后台重新拉取并刷新 | — |
| LRU | Least Recently Used | 按最后访问时间淘汰；⚠️ 播放缓存实际按写入时间（`cachedAt`）淘汰，见 TD-08 | — |
| 队列 | `PlayerController.queue` / `playlist` | 当前播放列表 | 播放列表（避免与歌单混淆） |
| 歌单 | `PlaylistSummary` / `PlaylistDetail` | 后端概念的歌单 | 播放列表 |
| 接续播放 | `settings.resume_playback_enabled` | 重新打开应用恢复上次队列与进度（不自动播放） | 断点续播 |
| 无缝播放 | `settings.gapless_playback_enabled` | 预加载下一首，减少切歌间隙 | 无间隙播放 |
| 桌面歌词 | Dart 侧 `DesktopLyricsService`（MethodChannel 封装）；Android 侧承载者 `LyricsOverlayService` + `KaraokeTextView` | 在其他应用上方显示歌词的悬浮窗 | 悬浮歌词、悬浮窗歌词 |
| 逐字歌词 | KRC 格式歌词 | 带词级时间戳的歌词格式 | 卡拉OK歌词 |
| 元数据行 | 歌词元数据行 | 歌词开头的署名、制作人、水印等非演唱行 | 版权行 |
| 后台打断机制 | `settings.audio_interruption_enabled` | 控制其他 App 能否打断本应用播放 | 音频焦点 |
| 音量闪避 | ducking | 被短暂打断时压低音量而非暂停 | 压低音量 |

## 2. 分层与角色术语

| 中文名 | 代码位置 | 职责 | 禁止写成 |
|---|---|---|---|
| 配置层 | `lib/config/` | 编译期常量与运行时覆盖（API 地址、缓存上限、TTL） | 常量层 |
| 核心层 | `lib/core/` | `ApiClient`：HTTP 传输、重试、超时、session | 网络层 |
| 服务层 | `lib/services/` | 无 UI 依赖的业务能力（API 封装、缓存、下载、音频、歌词） | Service 层 |
| 控制器层 | `lib/controllers/` | `ChangeNotifier` 状态与业务编排 | 状态层、ViewModel |
| UI 层 | `lib/ui/` | 页面、组件、主题、响应式布局 | 视图层 |
| 模型层 | `lib/models/` | 纯数据模型与 JSON 解析 | 实体层 |
| 装配点 | `lib/main.dart` | 手动依赖注入的唯一位置 | 入口 |
| 音频处理器 | `MusicAudioHandler` | `audio_service` 的 `BaseAudioHandler` 实现 | 播放服务 |
| 音频焦点闸门 | `AudioFocusGate` | 串行化焦点请求，防止并发抢占 | 焦点管理 |
