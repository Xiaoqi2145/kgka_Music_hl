# 接口联调与排障手册

## TL;DR

所有接口都走 `ApiClient → MusicApi → 领域模型` 一条链。**业务成功的唯一判定是响应体 `status == 1`**（`music_api.dart:578-580`），失败信息按 `msg → message → errmsg → error → error_msg` 顺序取第一条非空（`_failureSuffix`，`music_api.dart:592-612`）。排障三件套：`adb logcat` 过滤 `[KA Music]`、改自定义 API 地址指向本地后端、用 `curl` 对拍 `api.json`。

---

## 1. 请求链路

```
UI / Controller
  └─ MusicApi.xxx()                    // 业务语义、参数拼装
       └─ ApiClient.get/post(path, query/body)
            ├─ AppConfig.apiUri(path, query)   // base URL + 路径拼接 + 空值过滤
            ├─ _headers                          // Accept / Content-Type / X-Kg-Session-Id / t1
            ├─ _sendWithRetry                    // 超时、重试、退避
            ├─ _processResponse                  // 提取 sessionId、校验 2xx、jsonDecode
            └─ unwrapData                        // 若顶层有 data 字段则解包
  └─ asMap / asList / asString / asInt        // 模型解析容错
       └─ Model.fromJson                      // 领域模型
```

---

## 2. URL 构造规则（`app_config.dart:85-94`）

| 规则 | 说明 |
|---|---|
| base | `effectiveBaseUrl` = 自定义地址 ?? `apiBaseUrl` |
| 路径拼接 | base 的 path 若不以 `/` 结尾则补上，再拼 `path`（去掉开头 `/`） |
| 查询参数 | **空值/null 的键会被过滤掉**，不会发 `key=` |
| 示例 | base=`https://music.api.hoilai.cn`，path=`/song/url`，query=`{hash: 'ABC', quality: ''}` → `https://music.api.hoilai.cn/song/url?hash=ABC` |

> ⚠️ 因为空值被过滤，**后端拿不到「显式空参数」**，若某接口依赖空值语义需特别处理。

## 3. 请求头与鉴权

| 头 | 来源 | 说明 |
|---|---|---|
| `Accept` | 固定 | `application/json` |
| `Content-Type` | 固定 | `application/json` |
| `X-Kg-Session-Id` | `ApiClient.token` **或** `ApiClient.sessionId` | 两者都会写同名头，**后写的 sessionId 覆盖 token**（见 §7 坑） |
| `t1` | `ApiClient.t1` | 登录返回的辅助鉴权字段 |

**响应头**：`x-kg-session-id` 若存在会被自动保存到 `ApiClient.sessionId`（`api_client.dart:130-133`），用于后续请求关联登录态。

## 4. 成功/失败判定

### 4.1 业务成功

```dart
bool _isSuccess(Map<String, dynamic> json) => asInt(json['status']) == 1;
```

- `status` 缺失或非 1 → 视为失败。
- **注意**：HTTP 200 + `status != 1` 属于业务失败，`ApiClient` 不会抛异常，由 `MusicApi` 判断后抛 `ApiException`。

### 4.2 多账号选择

```dart
// music_api.dart:582-590
requiresUserSelection == true
或 (errorCode == 34175 && accounts 非空)
```

命中时返回 `PhoneLoginResult.accountSelection`，而不是失败。

### 4.3 失败信息提取顺序

`msg` → `message` → `errmsg` → `error` → `error_msg` → 若无则 `（错误码：error_code|errcode|code）`。

### 4.4 响应解包

`unwrapData(json)`：若顶层是 Map 且含 `data`，返回 `json['data']`，否则原样返回（`api_client.dart:145-153`）。

> ⚠️ 部分接口（如 `/fm/recommend`、`/fm/class`）的 `data` 是数组，`MusicApi` 里做了 `raw is List ? raw : asMap(raw)['data']` 的兼容处理。

## 5. 排障命令速查

### 5.1 查看应用日志

```powershell
# 全部 KA Music 日志
adb logcat -v time | Select-String "KA Music"

# 只看响度相关
adb logcat | Select-String -Pattern "loudness|VolumeNorm"

# 只看播放链路
adb logcat | Select-String -Pattern "\[KA Music\]\[playback\]"

# 只看 Flutter 异常
adb logcat | Select-String -Pattern "flutter|E/flutter"
```

### 5.2 指向本地后端联调

```powershell
# 方式一：编译期指定默认地址
flutter run --dart-define=KA_MUSIC_API_BASE_URL=http://192.168.1.10:5000

# 方式二：应用内设置（设置 → 网络 → API 服务器地址，或登录页设置入口）
```

> 注意：`android:usesCleartextTraffic="true"` 允许 HTTP 明文，本地联调可直接用 `http://`。

### 5.3 与后端对拍

```powershell
# 直接 curl 一个端点（替换 base 与参数）
curl "https://music.api.hoilai.cn/song/url?hash=YOUR_HASH&quality=128"

# 检查某个端点是否在契约中
node -e "const j=require('./api.json'); console.log(Object.keys(j.paths).filter(p=>p.includes('song')))"
```

## 6. 常见故障速查表

| 症状 | 可能原因 | 排查动作 |
|---|---|---|
| 登录后接口仍返回未登录 | session 未保存 / 被 `null` 覆盖 | 检查 `MusicApi.setSession` 是否被调用；确认 `sessionId` 非空（`music_api.dart:26-38` 有专门注释说明此坑） |
| 首次请求打到默认地址（自定义地址未生效） | `loadCustomBaseUrl()` 未在创建 `ApiClient` 前执行 | 确认 `main.dart:26` 顺序 |
| 首页空数据但网络正常 | `status != 1` 业务失败 | logcat 查 `_failureSuffix` 拼出的 message |
| 播放无地址 | `/song/url` 返回空 URL 或无版权 | 检查是否开启智能音质；curl 对拍 |
| 音量均衡不生效 | 后端未透传 `volume` 字段 | `adb logcat | Select-String loudness`，看响应 keys 是否含 `volume` |
| 封面不显示 | 缩略图下载失败或 URL 未归一化 | 检查 `normalizeImageUrl`；确认磁盘缓存目录存在 |
| 请求超时后无提示 | `ApiException` 被上层吞掉 | 检查调用方是否 `catch` 后静默 |
| 重复请求/流量异常 | 无请求去重，页面重复构建触发 | 检查页面 `initState` 与 `didChangeDependencies` 的调用次数 |
| 二维码不显示 | 图片 URL 或渲染问题 | 对照 v2.2.0 修复记录（扫码登录） |

## 7. 约束与坑

| 编号 | 问题 | 位置 | 影响 |
|---|---|---|---|
| API-01 | `token` 与 `sessionId` 都写 `X-Kg-Session-Id`，后者覆盖前者 | `api_client.dart:70-83` | 若后端期望 token 语义，会鉴权失败 |
| API-02 | 空查询参数被静默过滤 | `app_config.dart:90-92` | 无法传显式空值 |
| API-03 | `post` 默认 `allowRetry = false`，但调用方容易忽略 | `api_client.dart:47` | 写操作重复提交风险已规避，但读操作也不会重试 |
| API-04 | 无请求去重与并发限制 | `ApiClient` | 页面重复构建可能产生重复请求 |
| API-05 | `ApiException.message` 直接携带响应体 | `api_client.dart:137` | UI 可能展示原始 JSON/HTML |
| API-06 | `unwrapData` 只解一层 `data` | `api_client.dart:145-153` | 嵌套 `data.data` 需调用方再解 |
| API-07 | 调试日志用 `debugPrint` 且无开关 | `music_api.dart` 16 处 | release 也有输出 |
| API-08 | 无请求耗时与成功率指标 | `ApiClient` | 无法定位慢接口 |
