# 本地存储与配置项清单

## TL;DR

应用持久化分三类：**`SharedPreferences` 键（56 个）**、**文件系统目录（6 处）**、**编译期常量（`AppConfig`）**。键命名有两套风格——旧键用 `ka_music_*` / `cache_*`，新键统一用 `settings.*` / `theme.*`。**没有版本号与迁移框架**，键语义变化只能靠 `待核实` 与人工兼容代码。

## 2. 文件系统存储位置

| 用途 | 目录 API | 子目录/文件名 | 说明 |
|---|---|---|---|
| 数据缓存 | `getTemporaryDirectory()` | `data_cache/*.json` | ⚠️ 系统可清理；`AppConfig.cacheDirName` 未使用 |
| 缩略图缓存 | `getApplicationSupportDirectory()` | `ka_music_artwork/*.img` | LRU 上限 512MB |
| 播放缓存 | `getTemporaryDirectory()` | `ka_music_play_cache/{hash}_{q}.{mp3\|flac}` | ⚠️ 系统可清理；上限 300MB |
| 下载 | `getApplicationDocumentsDirectory()` | `ka_music_downloads/{hash}_{q}.{mp3\|flac}` | 无上限 |
| 播放历史 | `getApplicationSupportDirectory()` | `playback_history.json` | 已从 prefs 迁移 |
| 自定义背景图 | `getApplicationDocumentsDirectory()` | `bg_custom.{ext}` | 从相册复制，避免临时文件被清理 |

### 3.1 运行时覆盖

| 项 | 行为 |
|---|---|
| 自定义 API 地址 | `AppConfig.loadCustomBaseUrl()` 在 `main()` 首步执行；`effectiveBaseUrl` 优先返回自定义值 |
| 旧域名兼容 | `https://music.api.hoilai.com` 被视为「等同默认」，读取时自动清除（`app_config.dart:11,74-80`） |
| 空值处理 | 传入 `null`/空串/默认地址 → 清除自定义，回退默认 |

## 4. 迁移与兼容

| 迁移 | 机制 | 位置 |
|---|---|---|
| 数据缓存 prefs → 文件 | `read()` 命中 prefs 后写文件并删除 prefs 键 | `cache_service.dart:74-79` |
| 播放历史 prefs → 文件 | `_load()` 读到 prefs 后 `flush()` 到文件再删除 prefs 键 | `playback_history_service.dart:58-62` |
| 旧 API 域名 | 视为默认值并清除 | `app_config.dart:74-80` |

> ⚠️ **没有 schema 版本号**：无法判断某个键是「旧格式」还是「新格式」，迁移靠「读到旧载体就搬走」的隐式约定。

## 5. 约束与坑

| 编号 | 问题 | 影响 |
|---|---|---|
| K-01 | 键命名两套风格（`ka_music_*` 与 `settings.*`） | 检索与治理困难 |
| K-02 | 无 schema 版本 / 无迁移框架 | 键语义变更时无法自动升级 |
| K-03 | `settings.lyric_scale`、`playback_stats`、`ka_music_liked_hashes` 等默认值分散在 UI/服务中 | 新成员难以确认默认行为 |
| K-04 | `AppConfig.cacheDirName` 定义未用 | 误导 |
| K-05 | 凭证（token/t1/sessionId）明文存于 SharedPreferences | 见 `08-工程纪律/安全与合规纪律.md` |
| K-06 | 数据缓存与播放缓存位于临时目录，系统可清理 | 离线能力不可靠 |
| K-07 | `settings.bg_opacity` 语义为「值越大背景越明显」，与命名直觉相反 | 易误改 |
