## 1. 使用说明

### 1.1 字段定义

| 字段 | 取值 | 说明 |
|---|---|---|
| 编号 | `R-nn` | 两位序号，全局唯一，删除后不复用 |
| 类别 | 技术 / 依赖 / 合规 / 人力 / 进度 | 单值，取主要成因 |
| 概率 | 高 / 中 / 低 | 高 = 已发生或 > 60% 会发生；中 = 20% ~ 60%；低 = < 20% |
| 影响 | 高 / 中 / 低 | 高 = 阻断发布或造成用户数据/资金损失；中 = 功能受损但可绕过；低 = 体验或效率下降 |

| 责任人 | 角色（当前均为项目负责人） | 单人期不写人名，写角色 |
| 复查周期 | 每周 / 每迭代 / 每里程碑 / 每季度 | 见 §1.4 |
| 状态 | 开放 / 监控中 / 已关闭 | 关闭需在 §6 留记录 |

| 描述 | 音量均衡依赖 `/song/url` 响应中的 `volume`/`volume_gain`/`volume_peak`。App 侧解析与计算已完成，但**后端是否真的透传未确认**；未透传时 `LoudnessData.lufs` 为 null，功能静默旁路（gain = 1.0） |

## 7. 约束与坑

| # | 约束 / 坑 | 说明 |
|---|---|---|
| 1 | 责任人全是项目负责人 | 单人维护期风险责任无法分摊，等级只能靠「降低概率」而非「转移」 |
