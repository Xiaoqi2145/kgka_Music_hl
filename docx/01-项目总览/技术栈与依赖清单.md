## 一句话结论（TL;DR）

1. KA Music 是**单 package 的 Flutter 应用**（`kgka_music_hl`，`publish_to: 'none'`），**直接依赖仅 10 个第三方包 + Flutter SDK 本身**，全部来自 `pub.dev`，无 git / path 依赖，无 `dependency_overrides`（`pubspec.yaml:9-22`）。
2. 技术栈是**「原生方案优先」**：状态管理用 `ChangeNotifier`、路由用 Navigator 1.0、持久化用 `shared_preferences` + 文件系统，第三方库只承担四件事——音频引擎、后台播放、HTTP、平台目录/文件选择。
3. 传递依赖共 **96 个包**，其中体量最大的一支是 `audio_service → flutter_cache_manager → sqflite`（`flutter pub deps` 实测），它把 SQLite 整条链带进了 Android/iOS 产物。

## 5. 约束与坑

| 编号 | 约束 / 坑 | 证据 | 影响 |
|---|---|---|---|
| D-01 | `http` 与 `dio` **职责严格分离**：`http` 只用于 API（`lib/core/api_client.dart`），`dio` 只用于下载（`lib/services/download_service.dart`）。混用会破坏 `ApiClient` 的重试/session 单一入口。 | `lib/core/api_client.dart:5`、`lib/services/download_service.dart:4` | 新增网络能力必须先判断属于哪条链路 |
| D-02 | `.flutter-plugins-dependencies` **不在版本控制内**（`.gitignore:30`），且内容含开发者本机 pub 缓存绝对路径（本机为 `C:\Users\xiaoq\AppData\Local\Pub\Cache\...`）。换机后必须重新 `flutter pub get`。 | `.gitignore:30`、`.flutter-plugins-dependencies` | 不能把它当契约文档引用；平台矩阵以重新生成为准 |
| D-03 | `file_picker ^11.0.2` 使用 Kotlin Gradle Plugin（KGP），构建时有兼容性告警，未来 Flutter 版本可能不兼容。 | `KA-Music-项目状态.md` §4.3 | 升级 Flutter 时优先回归该插件 |
| D-04 | `sqflite` 整条链（`sqflite`/`sqflite_android`/`sqflite_darwin`/`sqflite_common`）**并非项目直接使用**，而是 `audio_service → flutter_cache_manager` 带入；项目自身的缓存全部走文件系统。 | `flutter pub deps` 树：`audio_service → flutter_cache_manager → sqflite` | 想删 SQLite 依赖只能换掉 `audio_service` 或等上游 |
