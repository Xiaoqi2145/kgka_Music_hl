## 一句话结论（TL;DR）

1. 本机是**单机 Windows 开发环境**：Flutter 3.44.4 stable（`D:\SDK\flutter`）+ Dart 3.12.2 + Android SDK 37.0.0（`D:\SDK\Android`）+ JDK 21（`D:\SDK\Java\jdk-21`），`flutter doctor` 仅 Web 一项报错（找不到 Chrome）。
2. Gradle **不由系统 PATH 的版本决定**：项目用 wrapper 固定 `gradle-8.14-all`（`android/gradle/wrapper/gradle-wrapper.properties:5`），而 PATH 上的 `gradle` 是 9.6.1，二者不同。
3. `PATH` 上的 `java` 是 Zulu 25，`JAVA_HOME` 指向 Temurin 21 —— Gradle 读 `JAVA_HOME`，所以当前构建走 21；一旦 `JAVA_HOME` 丢失，构建会落到 25 上，属于必须知道的隐性依赖。

## 7. 新机器从零搭环境（分步清单）

> 目标：能跑通 `flutter pub get` → `flutter test` → `flutter build apk --release`。命令中的路径需按新机器实际位置替换。

| 步骤 | 操作 | 命令 / 动作 | 验收 |

| 2 | 安装 Android cmdline-tools + platform-tools | 解压 `cmdline-tools` 到 `%ANDROID_HOME%\cmdline-tools\latest` | `sdkmanager --version` 可用 |
| 3 | 安装 SDK 组件 | `sdkmanager "platform-tools" "platforms;android-36" "build-tools;36.0.0" "ndk;28.2.13676358"` | `%ANDROID_HOME%\ndk\28.2.13676358` 存在 |
| 4 | 接受许可 | `flutter doctor --android-licenses` | 全部 accepted |
| 5 | 设置 `ANDROID_HOME` | 指向 Android SDK 根目录 | `flutter doctor -v` 显示 `ANDROID_HOME` |
| 6 | 安装 Flutter 3.44.4 stable | 克隆 `https://github.com/flutter/flutter.git` 或下载 stable 包，切到 3.44.4 | `flutter --version` 输出 3.44.4 |
| 7 | 配置国内镜像（可选） | `FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn` | `flutter doctor -v` 显示镜像地址 |

## 8. 约束与坑

| 编号 | 约束 / 坑 | 证据 | 影响 |
|---|---|---|---|
| K-01 | **Gradle 版本以 wrapper 为准**（8.14），PATH 上的 9.6.1 不参与项目构建。直接跑 `gradle` 而非 `.\gradlew` 会得到与 CI 不一致的结果。 | `android/gradle/wrapper/gradle-wrapper.properties:5`、`Get-Command gradle` | 构建命令统一用 `flutter build` 或 `android\gradlew` |
| K-02 | `PATH` 上的 `java` 是 **25**，`JAVA_HOME` 是 **21**。Gradle 走 `JAVA_HOME`；若 `JAVA_HOME` 丢失，AGP 8.11.1 会落到 JDK 25 上，可能直接失败。 | `java -version`、`flutter doctor -v` | 不要把 JDK 25 写进 `JAVA_HOME` |
| K-03 | `abiFilters += listOf("arm64-v8a")`（`android/app/build.gradle.kts:28-30`）**未在实际产物中生效**：实测 release APK 同时包含 `arm64-v8a`、`armeabi-v7a`、`x86_64` 三套 `libapp.so`/`libflutter.so`/`libdartjni.so`/`libdatastore_shared_counter.so`，APK 体积 61 543 537 字节（约 58.7 MB）。原因待核实。 | `android/app/build.gradle.kts:28-30` vs 对 `app-release.apk` 的 zip 列表 | 若真要只出 arm64，需在命令侧加 `--target-platform android-arm64` 或用 `--split-per-abi` |
| K-04 | `.vscode/settings.json:2` 的 `cmake.sourceDirectory` 指向 `E:/Project/Flutter/kgka_music_hl/linux`，与当前仓库路径 `E:\Project\Codex\Project\KAmusic` **不一致**，且该文件已进版本控制。 | `.vscode/settings.json:2`、`git ls-files` | 影响 VS Code 的 CMake 插件定位 Linux 工程；应改为相对/当前路径 |
| K-05 | Chrome 未安装/未配置，`flutter run -d chrome` 与 Web 端调试**当前不可用**。 | `flutter doctor -v` | Web 相关验证需先设 `CHROME_EXECUTABLE` |
| K-06 | `android/local.properties` 是机器相关文件且被忽略（`android/.gitignore:6`），但 `android/settings.gradle.kts:6-7` 在配置阶段就强制读取 `flutter.sdk`，缺失会以 `flutter.sdk not set in local.properties` 直接失败。 | `android/settings.gradle.kts:6-7` | 报错时先检查该文件 |
| K-07 | `android/gradle.properties:1` 申请 `-Xmx8G` + 4G Metaspace，机器内存不足时构建会 OOM 或极度缓慢。 | `android/gradle.properties:1` | 低配机器需下调并本地化（该文件已进版本控制） |
| K-08 | 文档中 Flutter SDK 路径大小写不一致：`KA-Music-项目状态.md` 头部写 `D:\SDK\Flutter`，`flutter doctor` 输出 `D:\SDK\flutter`（Windows 不区分大小写，但复制粘贴到脚本时需注意）。 | `KA-Music-项目状态.md:5` vs `flutter doctor -v` | 以 `local.properties:1` 的实际值为准 |
