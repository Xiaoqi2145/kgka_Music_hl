### 2.1 `test/artwork_cache_lru_test.dart` — LRU 淘汰纯函数

- **被测对象**：`ArtworkCacheService.selectLruEvictions(List<ArtworkCacheEntry> entries, int maxBytes)`，静态纯函数（`lib/services/artwork_cache_service.dart:257-280`）。
- **输入模型**：`ArtworkCacheEntry({required String path, required int size, required DateTime accessedAt})`（`artwork_cache_service.dart:11-23`）。
- **淘汰算法要点**：总量 `<= maxBytes` 时直接返回空（`:265`）；否则按 `accessedAt` 升序、**时间相同再按 `path` 升序**（`:267-271`），逐个扣减直到不超上限（`:274-278`）。

| # | 用例名 | 断言意图 |
|---|---|---|
| 1 | 总量未超过上限时不淘汰任何条目 | 200 < 1000 → `isEmpty` |
| 2 | 总量恰好等于上限时不淘汰 | 200 == 200 → `isEmpty`（边界：相等不淘汰） |
| 3 | 超出上限时淘汰最久未访问的条目 | 300 > 200 → 仅 `['old']` |
| 4 | 需要淘汰多条时按访问时间升序返回 | 300 > 100 → `['old','mid']`（**顺序敏感**） |
| 5 | 单个条目超过上限时同样被淘汰 | 单条 500 > 100 → `['huge']` |
| 6 | 访问时间相同时按路径稳定排序 | 时间相同 → 按 path 升序，返回 `['a']` |
| 7 | 空列表不抛异常 | `selectLruEvictions(const [], 0)` → `isEmpty` |

- **覆盖的边界**：空输入、总量等于上限、单条超限、淘汰多条、时间并列。
- **未覆盖的关键路径**：`_prune()` 的目录扫描与真实删除（`:216-252`）、`_enforceLimit()` 的并发合并（`_pruning`，`:193-205`）、`_pruneToLimit()` 的循环与死循环保护（`:207-214`）、`_touch()` 刷新访问时间（`:141-147`）、`clearCache()`（`:172-191`）、`setMaxCacheBytes()` 的取值钳位（`:162-169`）。

### 2.2 `test/audio_focus_gate_test.dart` — 音频焦点串行化状态机

- **被测对象**：`AudioFocusGate`（`lib/services/audio_focus_gate.dart:2-45`）。
- **接口**：构造 `AudioFocusGate({required Future<bool> Function(bool) setActive, bool resetBeforeAcquire = true})`；方法 `acquire()`、`release()`、`invalidate()`；代际计数 `_generation`（`:13`）、串行队列 `_tail`（`:12`）。

| # | 用例名 | 断言意图 |
|---|---|---|
| 1 | non-Android activation does not deactivate a playing session | `resetBeforeAcquire:false` 时只调一次 `setActive(true)`，释放时补 `false` |
| 2 | each play clears the cached request before requesting focus | 连续两次 `acquire` 的调用序列为 `[false,true,false,true,false]`（每次先清缓存） |
| 3 | denial is not playback permission and clears the cached request | `setActive(true)` 返回 false 时仍补一次 `setActive(false)` |
| 4 | failed deactivation never attempts activation | 取消失败（返回 false）时**不再尝试激活**，序列 `[false]` |
| 5 | pause during activation rejects and releases late focus grant | 激活途中 `release` → `acquire` 返回 false，且迟到的授权被释放 |
| 6 | interruption invalidates pending activation without an extra request | `invalidate()` 使挂起激活作废且不额外发请求 |
| 7 | latest simultaneous play wins | 两次并发 `acquire`：第一个 false、第二个 true |
| 8 | a platform error does not poison subsequent requests | 通道抛异常后下一次 `acquire` 仍可成功 |

### 2.7 `test/transition_coordinator_test.dart` — 播放实例标识与租约状态机（12 例）
