## 3. 重点条目详情

### TD-01 缩略图缓存计数被扫描快照覆盖（P1）— **已修复**

**证据（修复后）**：`artwork_cache_service.dart:275-278`

```dart
// Subtract only files deleted by this pass. Downloads may have completed
// during the scan and already incremented these live counters.
_totalBytes = _totalBytes > removedBytes ? _totalBytes - removedBytes : 0;
_entryCount = _entryCount > removedCount ? _entryCount - removedCount : 0;
```

**问题（历史）**：原实现为 `_totalBytes = total - removedBytes`，其中 `total` 是扫描**开始**时的目录总和。扫描期间 `_loadTracked` 可能已 `_totalBytes += downloaded.length()`，但随后被这行覆盖掉，导致计数偏小 → 上限可被突破。

**修复方式**：改为**按本轮实际删除量扣减**（不再用扫描快照整体赋值）。同一模式也应用在单文件删除路径（`invalidate`，`:162-163`）与 `clearCache`（`:217-218`）。仅在**启动扫描**时整体赋值（`:109-110`），此时不存在并发写入。

**验收**：新增单测：模拟扫描期间新增文件，断言 `_totalBytes` 与目录实际总和不漂移。**该单测尚未补**（`artwork_cache_service.dart` 的 `_prune` 仍属 §7 G-02 的覆盖缺口），故本条标「已修复（代码）」但**测试验收未闭环**。

### TD-02 缓存位于临时目录（P1）— **部分修复**

**证据**：
- 数据缓存**已迁至** `getApplicationSupportDirectory()`：`cache_service.dart:51-60`（`'${(await getApplicationSupportDirectory()).path}/$_cacheDirectoryName'`）。
- `cache_service.dart:62-65` 的 `getTemporaryDirectory()` **仅用于旧目录兼容**：`_legacyCacheDirectory()` 返回 `<temp>/data_cache`，只在**读取/清理旧数据**时被引用（`:109`、`:245`、`:265`、`:330`），不是主存储位置。
- 播放缓存**仍在临时目录**：`download_service.dart:62-69` 的 `playCacheDir()` 使用 `getTemporaryDirectory()`。

**问题（残留）**：Android 系统「清除缓存」会清空 `getTemporaryDirectory()`，**播放缓存因此仍可能被回收**，与「离线可播放」目标冲突。数据缓存与缩略图缓存均已使用持久目录，播放缓存是最后一个未迁的。

**建议**：播放缓存迁到 `getApplicationSupportDirectory()`，并做一次性迁移（旧目录存在则搬移）。

**验收**：手动清除系统缓存后，已缓存封面、已缓存数据与已缓存音频均仍可用。**当前仅前两项满足。**

### TD-03 release 使用 debug 签名（P1）

**证据**：`android/app/build.gradle.kts` → `signingConfig = signingConfigs.getByName("debug")`

**问题**：无法上架、无法覆盖安装升级、签名指纹不可控。

**建议**：引入 `key.properties`（不入库）+ `signingConfigs.release`；`buildKey.keystore` 从仓库移除并轮换密钥。

**验收**：`flutter build apk --release` 产物用 `apksigner verify --print-certs` 显示 release 证书。

### TD-04 无 CI 与崩溃上报（P1）

**问题**：137 次提交全部靠本地验证；`unawaited` 的异常被 `catch (_) {}` 吞掉，线上问题不可见。

**建议**：先落地本地门禁脚本（`flutter analyze` + `dart format --set-exit-if-changed` + `flutter test`），再接入 CI；错误上报可先用本地日志文件 + 用户导出。

**验收**：见 `08-工程纪律/测试与质量门禁.md` 的门禁命令全部可通过。

### TD-15 背景图渲染延迟（P2）

**证据**：`KA-Music-项目状态.md` §4.2

**现状**：用户反馈页面切换时背景图延迟约 0.7s。已尝试预加载字节、预解码 `ui.Image`、架构分离，均回退。当前 `main.dart` 用 `ResizeImage.resizeIfNeeded` + `gaplessPlayback: true` + 保持 `ImageStream` 存活（`_keepImageAlive`）。

**建议方向**：`Image.file()` 的缓存键问题、Navigator 过渡动画与图片解码的时序同步；可用 DevTools 时间线定位。

**验收**：录屏逐帧确认页面切换后背景图在首帧或第 2 帧内出现。
