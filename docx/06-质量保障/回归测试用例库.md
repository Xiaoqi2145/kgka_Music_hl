# 回归测试用例库

## TL;DR

共 **68 条**手工回归用例，覆盖 11 个功能域。每条标注「必测 / 选测」与关联模块。**每次发布前必须执行全部「必测」用例**（42 条，约 90 分钟）。用例编号 `RC-<域>-<序号>` 全局唯一，缺陷修复后必须补充或关联对应用例。

## 0. 使用说明

| 字段 | 含义 |
|---|---|
| 编号 | `RC-<域缩写>-<两位序号>` |
| 级别 | **必测** = 每次发布前执行；**选测** = 相关模块改动时执行 |
| 环境 | 除非特别说明，均在 Android 真机、4G/WiFi、已登录状态下执行 |
| 结果 | 记录「通过 / 失败 / 阻塞」，失败必须开缺陷单 |

**域缩写**：`AU` 认证、`HM` 首页发现、`SE` 搜索、`PL` 播放、`LY` 歌词、`EF` 音效、`DL` 下载、`CA` 缓存、`ST` 设置、`LC` 本地音乐、`LB` 音乐库/云盘。
