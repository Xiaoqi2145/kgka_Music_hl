## 这是什么

这是一套**面向工程推进的本地知识库**，不是产品说明书。它把 KA Music 这个 Flutter 项目的
代码事实、接口契约、平台差异、技术债、推进计划与团队纪律，全部沉淀为可检索、可核对、可交接的文档。

三条使用原则：

1. **文档与代码一致**。任何文档结论都能在代码里找到锚点（`文件:行` 或 `文件:方法`）。
2. **契约优先**。`04-数据与接口/` 与 `05-平台与原生/` 属于契约级文档，改动即失效，必须同步更新。
3. **计划与纪律可执行**。`07-` 的每个任务都有验收标准，`08-` 的每条纪律都有执行方式与违反后果。
