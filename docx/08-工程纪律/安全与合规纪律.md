# 安全与合规纪律

## TL;DR

当前存在三项高优先级风险：buildKey.keystore 已被 Git 跟踪、token/t1/sessionId 明文存 SharedPreferences、Android 允许明文流量。项目 README 已声明仅供学习交流，但这不能替代授权、隐私政策和依赖许可证核查。任何密钥、凭证、用户数据或第三方 API 变更都必须先做安全评审。

## 1. 密钥与签名

| 资产 | 当前状态 | 纪律 |
|---|---|---|
| buildKey.keystore | 已被 Git 跟踪（TD-31） | 视为泄露；轮换、从当前树和历史移除、通知相关人员 |
| release 签名 | 当前使用 debug 签名（TD-03） | 使用 key.properties + 环境变量注入，密钥不入库 |
| API token/t1/sessionId | SharedPreferences 明文（TD-30） | 迁移至平台安全存储；日志与缺陷附件必须脱敏 |
| local.properties | 本地环境文件 | 不得提交，发布日志不得暴露路径 |

禁止：把密钥写入 Dart 常量、提交 APK/keystore、把 token 放进 debugPrint、在 PR 截图中展示二维码或账号信息。

## 2. 网络与鉴权

- AndroidManifest 当前 usesCleartextTraffic=true；仅允许本地联调临时使用，正式构建必须关闭或限制域名。
- 自定义 API 地址允许用户输入，必须校验 scheme、域名、证书、重定向和明文策略。
- HTTPS 证书错误不得静默绕过；不得用“信任所有证书”解决联调。
- ApiClient 的 session header、t1、响应 sessionId 变化必须有脱敏日志和测试。
- 网易云外链不走自定义 API，也不带后端鉴权，必须在平台/合规文档中明确。

## 3. 权限最小化

当前清单含 INTERNET、WAKE_LOCK、MODIFY_AUDIO_SETTINGS、FOREGROUND_SERVICE、媒体播放/特殊用途前台服务、REQUEST_INSTALL_PACKAGES、SYSTEM_ALERT_WINDOW 等权限。新增权限必须说明：功能目的、申请时机、拒绝降级、平台版本、隐私影响、移除条件。

禁止为了“方便”加入 MANAGE_EXTERNAL_STORAGE、无关联系人/定位/电话权限。桌面歌词悬浮窗、APK 安装、通知权限都必须有用户可见解释。

## 4. 隐私与数据

| 数据 | 当前行为 | 处理纪律 |
|---|---|---|
| token/t1/sessionId/userId | 本地保存 | 加密；退出登录清理；不得上报 |
| 播放历史/统计 | 本地持久化 | 提供清理；导出/日志脱敏 |
| 听歌时长 | 通过 /listen/timeadd 上报 | 明示目的、开关、失败策略和隐私政策 |
| 搜索词 | 本地保存最近 20 条 | 提供单条删除与清空 |
| 自定义背景图/本地音乐路径 | 本地使用 | 不上传；日志不得带完整路径 |
| API 请求 | 第三方后端 | 明示第三方服务和数据边界 |

应用必须提供隐私政策入口，说明收集、用途、保存期限、删除方式、第三方处理者和联系方式。

## 5. 第三方 API 与许可证

- KuGou Music API 为第三方接口，api.json 仅是技术契约，不代表授权。
- README 的学习交流/非商业声明必须保留，但发布前仍需确认接口使用、音乐版权、账号体系和分发渠道的法律边界。
- 运行 node 或包管理器查看依赖许可证；新增依赖必须记录许可证、平台、版本和漏洞状态。
- 不复制第三方受限代码，不把上游密钥或内部接口写进公开文档。

## 6. 发布安全门禁

发布前逐项确认：签名非 debug；keystore 不在 Git；APK versionCode 单调；usesCleartextTraffic 策略明确；权限清单与隐私政策一致；更新包来源和完整性校验明确；日志无凭证；依赖许可证清单已更新；第三方 API 免责声明可访问。

## 7. 约束与坑

- 删除当前 keystore 不等于历史未泄露，必须轮换。
- SharedPreferences 不是安全存储，不能因为“应用沙箱”就视为足够。
- usesCleartextTraffic 对自定义私有 API 很方便，但会扩大 MITM 面。
- REQUEST_INSTALL_PACKAGES 与 SYSTEM_ALERT_WINDOW 属高风险权限，必须说明用途和替代方案。
- “仅供学习”不是商业、版权、隐私或安全合规的自动豁免。
