~~~dart
final client = ApiClient()..token = session?.token;
final json = await client.get('/song/url', {'hash': song.hash});
~~~

~~~dart
final playUrl = await api.songUrl(song.hash, quality: quality);
~~~

## 5. 异步与错误处理

| 规则 | 内容 |
|---|---|
| R5.1 | 新增 `catch` 必须限定类型（`on Exception` / `on PlatformException` / `on FormatException`） |
| R5.2 | 禁止 `catch (_) {}` 空实现；至少一行 `debugPrint` |
| R5.3 | 不得吞掉 `Error`（`StateError` / `TypeError`）——那是程序缺陷 |
| R5.4 | 有意丢弃的 Future 必须 `unawaited(...)` 且内部自带 `try/catch` |
| R5.5 | 所有 HTTP 必须经 `ApiClient`（单次 15s / 总体 45s 超时、最多 2 次重试） |
| R5.6 | POST 默认不重试（`allowRetry: false`），仅幂等写操作显式开启 |

反例（空 catch，全库 22 处同型）：

~~~dart
try {
  await _api.addListeningTime();
} catch (_) {}
~~~

正例（`lib/controllers/player_controller.dart:2687-2705` 实际写法）：

~~~dart
try {
  await _api.addListeningTime();
} catch (error) {
  debugPrint('[KA Music][listen-time] report failed: $error');
}
~~~

更优（限定类型）：

~~~dart
try {
  await _api.addListeningTime();
} on ApiException catch (error) {
  debugPrint('[KA Music][listen-time] api error: $error');
} on SocketException catch (error) {
  debugPrint('[KA Music][listen-time] network error: $error');
}
~~~

反例（丢弃 Future）：`_statsService.addListenTime(_listenTimeReportInterval);`
正例（`player_controller.dart:2690`）：`unawaited(_statsService.addListenTime(_listenTimeReportInterval));`

重试与超时锚点：`lib/core/api_client.dart:78-118`（deadline 与重试）、`:96-101`（可重试状态码 500/502/503/504）。
